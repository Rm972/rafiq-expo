# رفيق الزائر الذكي (النسخة الكاملة)
هاكثون إكسبو 2030 الرياض · المسار 1 · التحدي 1.3

## الفكرة
يساعد الزائر على اختيار الفعاليات المناسبة حين تتزامن البرامج. **الذكاء الاصطناعي يقدّر الملاءمة، والكود يضمن عدم التعارض.**

## ماذا في المشروع
| المتطلب | ما نفّذناه |
|---|---|
| UI/UX | 8 شاشات: التفضيلات، الرئيسية، تفاصيل الفعالية، جدولي، المساعد، الخريطة، لا نتائج، النسخة الإنجليزية (RTL/LTR) |
| تطبيق ويب | خادم FastAPI + واجهة HTML/CSS/JS تعمل على الجوال والحاسب |
| الذكاء الاصطناعي | غابة عشوائية (RandomForest) مدرَّبة على بيانات اصطناعية، ومساعد يفهم الكلمات المفتاحية + TF-IDF ويستخدم النموذج |

## التشغيل على ويندوز
1. افتح المجلد في VS Code ثم الطرفية (Terminal) داخل مجلد المشروع.
2. `python -m venv venv` ثم `venv\Scripts\activate` ثم `pip install -r requirements.txt`
3. `uvicorn app.main:app --reload`
4. افتح http://127.0.0.1:8000/site/
(أو انقر مرتين على `run.bat`). أول تشغيل يدرّب النموذج تلقائياً خلال ثوانٍ.

لإعادة التوليد والتدريب يدوياً: `python -m app.make_data` ثم `python -m app.train` (من مجلد المشروع).

## الإفصاح والحدود
- البيانات **اصطناعية**: 30 فعالية، 500 زائر افتراضي، 5000 مثال. الإعجاب فيها مولَّد بقواعد افتراضية مع عشوائية.
- قيمة AUC ظاهرة في التطبيق (شاشة التفضيلات). بما أن البيانات مولَّدة بقواعد قريبة من خصائص النموذج، فهي تثبت أن الخط التقني يعمل ولا تثبت دقة على زوار حقيقيين.
- المساعد ليس نموذجاً لغوياً: يفهم كلمات مفتاحية وتشابه نصوص.
- التنقل: الزمن بين القاعات = المسافة ÷ 80 متراً في الدقيقة + 5 دقائق (إحداثيات القاعات تجريبية).
- الخطوة التالية: بيانات حقيقية، ومزيد من الأيام والفعاليات.

## الملفات
- `app/logic.py` المنطق: النموذج، التعارض، التوصية، المساعد، المسار

- `app/features.py`, `make_data.py`, `train.py` الميزات وتوليد البيانات والتدريب
- `data/` الفعاليات والقاعات والتدريب
- `static/` الواجهة
